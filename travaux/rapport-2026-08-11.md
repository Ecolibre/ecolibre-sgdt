## 2. Résultats de reconnaissance

### 2.1 Tâche 0 — Versions et documentation Page Forms

`action=query&meta=siteinfo&siprop=general|extensions` : MediaWiki 1.39.11
(PHP 7.4.33), Semantic MediaWiki 4.2.0, Semantic Result Formats 4.2.1,
**Page Forms 5.8.1**, Lockdown installée (vcs-date 2025-12-22) — tranche une
question ouverte du §6 de la passation.

Lecture directe (`action=raw`) des pages officielles *Defining forms*,
*Input types*, *Page Forms and templates*, *Values, mappings and
autocompletion* sur mediawiki.org :

- **`holds template` n'est pas un marqueur de masquage conditionnel** : c'est
  un paramètre de champ documenté sous « Embedded templates », pour qu'un
  champ stocke une série d'appels d'un autre modèle (gabarit multi-instance
  imbriqué comme valeur d'un paramètre). Hypothèse du cadrage réfutée par la
  documentation elle-même (confirmé et expliqué mécaniquement par
  l'amendement n°1 via lecture du code source de Page Forms 5.8.1 :
  `PF_FormField.php:276`, `PF_FormPrinter.php:470/1161`).
- **Masquer un bloc `for template` entier sans appel vide** : non documenté
  dans les quatre pages officielles. Le seul mécanisme documenté d'un bloc
  réellement optionnel est le template multi-instance à `minimum
  instances=0` — confirmé mécaniquement par l'amendement n°1
  (`PF_FormPrinter.php:1101-1102`, `addTemplate()` non appelé si
  `!allInstancesPrinted()`).
- **Transclusion d'une sous-page contenant `for template`/`field`** :
  documenté et supporté (« Reusing form elements ») ; condition : échapper
  les balises (`&#123;`/`&#124;`/`&#125;`) ou les entourer de `<nowiki>`, la
  définition de formulaire étant parsée deux fois (la première passe
  transcluant). Confirmé plus tard, en Tâche 7, que l'échappement doit
  porter sur chaque balise individuellement, pas sur le bloc entier.
- **`values from category` sur `checkboxes`** : documenté — la doc range
  explicitement `checkboxes` parmi les types à « ensemble fini d'options »
  couverts par les paramètres `values…`.
- **`$wgPageFormsFormCacheType`** : aucune interaction documentée avec la
  transclusion ; seule réserve documentée concerne les éléments à affichage
  dynamique (`{{PAGENAME}}`, `{{CURRENTUSER}}`), sans rapport.

### 6.12 Bug distinct trouvé — table wiki incompatible avec `{{#if:}}`, non lié au verrou SMW

Cyril signale : le rendu de `Bac à sable facettes` fait apparaître une
accolade ouvrante isolée (`{`) entre le tableau d'`Organic item` et la
catégorie, et le tableau de `Modèle:Organic facet plant` ne s'affiche pas
du tout — alors que le `#set` fonctionne (§6.11).

**Diagnostic, en lecture seule via `action=expandtemplates` (aucune
écriture) :**
- Comptage manuel des accolades du modèle : équilibré (`{{#if:` ouvert
  ligne 6, `{{#set:` ouvert ligne 7 et refermé ligne 61, `{{#if:` refermé
  ligne 194). Pas de `{ |` mal tapé, pas de `{{#if:` non refermé — les deux
  pistes suggérées par Cyril sont écartées.
- `action=expandtemplates` sur `{{Organic facet plant|Taxon_name=…|
  Forest_garden_layer=…|Adult_height=3}}` (les paramètres réels de la
  page) : sortie = un unique caractère `{`. Confirmé aussi en substituant
  les paramètres à la main dans le wikitexte réel du modèle et en le
  passant tel quel à `expandtemplates`.
- Bissection par tests isolés (aucun n'a touché au wiki, tous via
  `expandtemplates` sur du texte arbitraire) : `#if`+`#set` seuls → sain
  (sortie vide, attendu, `#set` ne produit rien à l'affichage). En ajoutant
  ensuite **une table wiki vide** (`{| class="wikitable"\n|}`) à
  l'intérieur du même `{{#if:}}` → cassé, même sortie `{`. Reproduit en
  minimal, sans aucun rapport avec le contenu réel du modèle :
  ```
  {{#if:1|
  {| class="wikitable"
  |}
  }}
  ```
  → `{`
- **Cause : incompatibilité connue de MediaWiki/ParserFunctions.** Une
  table en syntaxe wiki (`{|`/`|}`/`|-`/`!`/`|`) imbriquée dans l'argument
  d'un `{{#if:}}` n'est pas protégée par des accolades comme le serait un
  appel de modèle imbriqué ; ses nombreux caractères `|` sont donc comptés
  par le préprocesseur comme des séparateurs d'arguments du `#if`
